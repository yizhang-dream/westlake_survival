# Research & careers

## Scholar

```bash
westlake scholar dbs               # subscribed database registry
westlake scholar open cnki         # entry point for a database
westlake scholar campus            # on-campus IP beacon
westlake scholar doi 10.1038/... -o out.pdf   # DOI → PDF full text (on-campus subscriptions)
westlake scholar ensure            # off-campus: one command to revive the CARSI SSO session
```

`scholar ensure` needs the `[browser]` extra; the rest need no account (publishers authenticate by IP on campus).

## Curriculum (program)

```bash
westlake program plan [major]      # credit requirements + course tables
westlake program curriculum        # course system
westlake program majors            # majors
westlake program courses           # general-education catalog
westlake program course ML         # cross-source course search
```

## Research support

```bash
westlake research latest           # research news
westlake faculty search <keyword>  # faculty directory
westlake hpc overview              # HPC cluster queues
westlake finance sections          # reimbursement rules
westlake news                      # university news
westlake events                    # lectures & events
```

## Careers

```bash
westlake careers                   # latest job posts
westlake career deep --kind campus|jobfair|teachin   # deep lists
westlake career detail <id>        # detail
```
